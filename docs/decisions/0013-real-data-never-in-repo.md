# 0013 — البيانات الحقيقية لا تدخل المستودع العام
- **الحالة:** معتمد — 2026-10-26

## السياق
المستودع عام (قرار صاحب المشروع). نسخ بيانات المحل فيها أسماء زبائن وأرقام هواتفهم
وديونهم.

## القرار
- نسخ البيانات الحقيقية تُستعمل **للتجربة محلياً فقط** (مثل اختبار النقل في المرحلة 2)،
  ولا تُرفع إلى المستودع أبداً، ولا تُنسخ إلى مجلداته.
- بيانات الاختبار **من المولّد** (`tools/gen/`) بأسماء صناعية.
- المفاتيح الخاصة، وكلمات سر الربط، وأسماء قنوات الإشعار **لا تُكتب في المستودع**.
