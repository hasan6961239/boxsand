# 0002 — .NET Framework 4.8، وكود يقبله مترجم ويندوز المدمج
- **الحالة:** معتمد — 2026-10-26

## السياق
أجهزة المحلات ويندوز 10/11، وكثيراً بلا إنترنت. المحرك الحالي .NET Framework 4،
ويُبنى بـ `build.bat` بمترجم C# الموجود في كل ويندوز بلا تثبيت أي شيء.

## القرار
- المحرك يستهدف **.NET Framework 4.8** (موجود في ويندوز 10 منذ 2019، وفي كل ويندوز 11).
- الكود يبقى مقبولاً من **مترجم ويندوز المدمج (C# 5)**، فيبقى `build.bat` يعمل على أي
  ويندوز. الاختبار الآلي على ويندوز يتأكد من ذلك مع كل تعديل.
- التراخيص والنسخ الاحتياطي تنتقل من المحرك الحالي كما هي.

## البدائل
- **.NET 10** (الأحدث، دعم حتى 2028): لغة أحدث، لكنه يحتاج تثبيت بيئة التشغيل على
  أجهزة بلا إنترنت أو ملف تثبيت بنحو 70 ميغا، ودعمه ينتهي بعد سنتين فنضطر لترقيته.
  .NET Framework 4.8 جزء من ويندوز نفسه ويُدعم معه.

## الثمن
- لغة أقدم: لا `$"..."` ولا `?.` ولا `nameof`. مقبول، فالمهم الثبات.
