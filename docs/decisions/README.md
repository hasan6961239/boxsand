# سجل القرارات

كل قرار يغيّر شكل المنظومة يُكتب هنا **مع سببه وبدائله وثمنه**، حتى يعرف من يأتي بعد
سنين لماذا بُنيت هكذا، ولا يعيد نقاشاً حُسم أو يكسر شيئاً عن غير قصد.

- القرار لا يُعدَّل بعد اعتماده. إن تغيّر الرأي يُكتب قرار جديد يقول «يحل محل 00XX».
- الترقيم تسلسلي، والاسم قصير بالإنجليزية لسهولة الروابط، والمحتوى بالعربية.
- الخطة المعتمدة: [`docs/plan/README.md`](../plan/README.md).

## قالب قرار جديد

```
# 00XX — العنوان
- **الحالة:** مقترح / معتمد — التاريخ
## السياق        ما المشكلة، وما الأرقام
## القرار        ماذا اخترنا بالضبط
## البدائل       ما الذي رُفض ولماذا
## الثمن         ما الذي نخسره أو نتحمّله بهذا القرار
```
