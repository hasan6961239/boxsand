# 0010 — مطابقة الكتب بين الفرعين تُحسب عند وصول الربط
- **الحالة:** معتمد — 2026-10-26

## السياق
الفرعان يسجّلان الكتاب نفسه بأسماء مختلفة: «فيزياء أساسية الجزء التاني / د. أشرف
محمود» في مصراتة، و«فيزياء أساسية 2 / دكتور أشرف محمود» في طرابلس.

## القرار
- لكل صنف **مفتاح مطابقة:** العنوان والمؤلف بعد التوحيد (0009)، وISBN-13 القانوني
  إن وُجد (ISBN-10 يُحوَّل).
- **التشابه يُحسب عند وصول بيانات الفرع الآخر** ويُخزَّن، فيظهر في البحث فوراً.
- **العتبات:**
  - ISBN متطابق، أو تشابه عالٍ مع تطابق المؤلف ← «غالباً نفس الكتاب».
  - تشابه متوسط ← «كتاب مشابه».
  - الموظف هو من يقرر.
- **مجموعة أمثلة ثابتة** (أولها مثال «فيزياء أساسية») تُختبر مع كل تعديل، وتُضبط
  العتبات عليها.

## الثمن
- حساب إضافي عند كل ربط (في الخلفية، على المتغيّر فقط).
