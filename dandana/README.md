# دندنة 🎶 — مكتبة أغانيك على الآيفون

تطبيق ويب (PWA) يتثبّت على الشاشة الرئيسية للآيفون ويشتغل كأنه تطبيق: أغانيك وفيديوهاتك
مخزّنة داخله وتشتغل بدون إنترنت، مع تحميل من يوتيوب، ريلز، راديو، واقتراحات على ذوقك.

```
dandana/
  app/      التطبيق نفسه (ملفات ثابتة — تُرفع على أي استضافة https)
  server/   «خادم دندنة»: برنامج صغير للبحث والتحميل من يوتيوب (يشتغل على كمبيوتر في البيت)
```

---

## المميزات

| | |
|---|---|
| **مكتبتك** | استيراد ملفات صوت وفيديو (MP3، M4A، AAC، WAV، FLAC، MP4، MOV…) من «الملفات» أو ألبوم الصور. استيراد **ملف ZIP** واحد فيه مئات الأغاني. قراءة الاسم والفنان والألبوم والغلاف والكلمات من الملف، مع إصلاح الوسوم العربية القديمة (Windows-1256)، واستنتاج الفنان من اسم الملف. كشف التكرار. |
| **المشغّل** | تحكم من شاشة القفل والسماعات، يكمل بعد قفل الشاشة، عشوائي ذكي (ما يكرر نفس الفنان ورا بعض)، تكرار، قائمة انتظار قابلة للترتيب، مؤقت نوم، سرعة تشغيل، تشغيل الفيديو كصوت، يتذكر آخر قائمة وموضع. |
| **الكلمات** | كلمات متزامنة مع الأغنية (من LRCLIB أو من الملف)، اضغط سطر للانتقال له. |
| **التحميل** | **بدون كمبيوتر:** الصق رابط يوتيوب أو تيك توك أو إنستغرام أو ساوند كلاود أو فيسبوك أو إكس، واختر صوت MP3 أو فيديو 360/480/720/1080. يمر عبر خوادم cobalt المجانية مع تبديل تلقائي بينها. تشغيل مباشر بدون حفظ، و«احفظها في مكتبتي» بعدها. مدير تحميلات مع تقدم. |
| **يوتيوب** | بحث وتصفح، قوائم تشغيل كاملة، أغانٍ مشابهة — بمفتاح يوتيوب الرسمي المجاني (أو خادم البيت). |
| **الثيمات** | 10 ثيمات كاملة: ليل، أسود (AMOLED)، طرب، بحر، زمرّد، ورد، بنفسج، غروب، نهار، رمل — أو «تلقائي» حسب وضع الجهاز، مع 8 ألوان للأزرار. زر 🎨 في الرئيسية. |
| **ريلز** | سحب عمودي: «مكتبتي» (مقاطع من أجمل جزء في أغانيك وفيديوهاتك) و«يوتيوب» (مقاطع قصيرة لفنانينك المفضلين، في مشغّل يوتيوب الرسمي المدمج). ضغطتين = مفضلة/حفظ. |
| **على ذوقي** | يحلل الفنانين اللي تسمعهم وتحبهم وتتخطاهم، ويقترح أغاني جديدة **مش موجودة عندك** (مع مقطع تجريبي 30 ثانية). «شغّل على ذوقي» = ميكس لا ينتهي يخلط أغانيك مع أغاني جديدة. فنانون قد يعجبونك. |
| **راديو** | محطات ليبية وعربية وعالمية مباشرة (Radio Browser)، بحث، مفضلة. |
| **تنظيم** | قوائم تشغيل، قوائم ذكية (المفضلة، الأكثر استماعاً، استمعت مؤخراً، لم تسمعها بعد…)، صفحات فنانين وألبومات، تحديد متعدد، تعديل المعلومات والغلاف. |
| **إحصائيات** | وقت الاستماع، آخر 14 يوم، أكثر الفنانين والأغاني. |
| **أخرى** | نسخة احتياطية للقوائم والمفضلة، حماية التخزين من الحذف التلقائي. |

> **عن ربط تيك توك وإنستغرام:** المنصتان ما توفران أي طريقة رسمية لجلب «فيد» ريلز لتطبيق
> خارجي، فبنينا الريلز من أغانيك ومن مقاطع يوتيوب القصيرة بدلاً منهما.

## ١) نشر التطبيق والحصول على رابط

التطبيق ملفات ثابتة في مجلد `app/`. أسهل طريقة:

1. افتح <https://app.netlify.com/drop> من الكمبيوتر (سجّل دخول).
2. اسحب مجلد **`dandana/app`** وأفلته في الصفحة.
3. يعطيك رابط مثل `https://xxxx.netlify.app` — تقدر تغيّر الاسم من إعدادات الموقع.

أي استضافة **https** ثابتة تنفع (GitHub Pages، Cloudflare Pages…). المهم أن الرابط **ما يتغيّر**:
مكتبتك مربوطة بعنوان الموقع، ولو تغيّر العنوان تبدأ مكتبة جديدة فاضية.

## ٢) التثبيت على الآيفون

1. افتح الرابط في **سفاري**.
2. زر المشاركة ⬆️ ← **«إضافة إلى الشاشة الرئيسية»**.
3. افتح دندنة من الأيقونة، ومن **داخلها** أضف أغانيك.

**مهم:**
- مكتبة التطبيق المثبّت منفصلة عن سفاري. أضف الأغاني من التطبيق المثبّت، مش من سفاري.
- حذف الأيقونة يحذف الأغاني المخزنة فيه. خلّي ملفاتك الأصلية في «الملفات» أو iCloud.
- من الإعدادات ← «حماية التخزين» حتى ما يحذفها النظام عند امتلاء الجهاز.
- 500 أغنية ≈ 2–4 جيجا. التطبيق يعرض المساحة المستخدمة والمتاحة في الإعدادات.

### إضافة 500 أغنية دفعة وحدة
1. حط الأغاني في مجلد داخل تطبيق «الملفات».
2. اضغط مطولاً على المجلد ← **«ضغط»** ← يطلع ملف `ZIP`.
3. في دندنة: مكتبتي ← ＋ ← اختر ملف الـ ZIP. يستخرج ويضيف الكل (خلي التطبيق مفتوح).

## ٣) التحميل — ثلاث طرق

| الطريقة | يحتاج | يعطيك |
|---|---|---|
| **مدمج (بدون إعداد)** | لا شيء | تحميل من رابط: يوتيوب، تيك توك، إنستغرام، ساوند كلاود، فيسبوك، إكس |
| **مفتاح يوتيوب** | مفتاح مجاني من جوجل (3 دقائق) | البحث والتصفح داخل التطبيق، القوائم، ريلز يوتيوب، أغاني جديدة في «على ذوقي» |
| **خادم البيت** | كمبيوتر في البيت | الأثبت والأسرع، M4A، ميكس يوتيوب |

### أ. المدمج: خوادم cobalt المجانية
[cobalt](https://github.com/imputnet/cobalt) برنامج تحميل مفتوح المصدر يشغّله متطوعون. التطبيق يجرّب الخوادم
بالترتيب، ولو خادم فشل أو رجّع ملف فاضي ينتقل للي بعده، ويتذكر الخوادم الشغّالة ويقدّمها.

- قائمة الخوادم في `app/instances.json` — حدّثها وأعد النشر بدون ما تلمس الكود.
- تقدر تضيف خادم cobalt خاص (ومفتاح Api-Key له) من الإعدادات.
- **بصراحة:** بتاريخ 13 نوفمبر 2026 فحصنا حوالي 70 خادماً منشوراً: 3 فقط رجّعت ملفات يوتيوب حقيقية بدون
  تسجيل دخول، وواحد منها يمنع المتصفحات، فبقي اثنان في القائمة. نجحت أغانٍ كثيرة (وتحميلان كاملان من داخل
  التطبيق: صوت وفيديو)، لكن من 14 أغنية عربية نجحت 4 فقط. يوتيوب يحجب هذه الخوادم من وقت لآخر، فالنتيجة تتغير.
  لو تبي ثبات كامل استعمل خادم البيت.

### ب. مفتاح يوتيوب (YouTube Data API v3)
واجهة يوتيوب الرسمية. الحصة المجانية 10,000 وحدة يومياً (البحث = 100 وحدة، يعني ~100 بحث في اليوم).
1. افتح `console.cloud.google.com` وسجّل بحساب جوجل.
2. «Select a project» ← «New project» ← Create.
3. ابحث عن **YouTube Data API v3** ← Enable.
4. «APIs & Services» ← «Credentials» ← «Create credentials» ← «API key».
5. انسخ المفتاح (يبدأ بـ `AIza`) ← دندنة: الإعدادات ← «مفتاح يوتيوب» ← «حفظ واختبار».

اختياري: قيّد المفتاح بـ «Websites» وحط رابط موقع دندنة.

### ج. خادم البيت (اختياري)

سفاري ما يسمح لأي موقع بالتحميل من يوتيوب مباشرة، فالبحث والتحميل والريلز من يوتيوب تمر عبر
برنامج صغير (Python + yt-dlp) يشتغل على كمبيوتر. **شغّله في البيت:** يوتيوب يحجب سيرفرات
الإنترنت السحابية عن التحميل («Sign in to confirm you're not a bot») — جربنا هذا فعلاً — بينما
يشتغل عادي من إنترنت البيت.

### ويندوز
```powershell
winget install Python.Python.3.12 Gyan.FFmpeg DenoLand.Deno Cloudflare.cloudflared
```
بعدها افتح مجلد `dandana\server` واضغط مرتين على **`start.bat`**.

### ماك
```bash
brew install python ffmpeg deno cloudflared
cd dandana/server && ./start.sh
```

أول تشغيل يثبّت المتطلبات تلقائياً، وبعدها يطبع: `الخادم يعمل على http://localhost:8765`.

### وصول الآيفون للخادم (https)
التطبيق على https، فلازم الخادم يكون https كمان. في نافذة ثانية:
```bash
cloudflared tunnel --url http://localhost:8765
```
انسخ الرابط `https://….trycloudflare.com` ← في دندنة: الإعدادات ← «رابط الخادم» ← «حفظ واختبار».
لما يطلع «متصل ✓» كل شيء جاهز.

**رابط ثابت (بدل ما يتغيّر كل مرة):**
- **Tailscale Funnel** (مجاني): ثبّت Tailscale على الكمبيوتر ثم `tailscale funnel 8765` ← رابط ثابت
  مثل `https://جهازك.xxxx.ts.net`.
- أو نفق Cloudflare مسمّى على نطاق تملكه (`cloudflared tunnel create` …).

### الأمان
أي شخص يعرف الرابط يقدر يستخدم خادمك. حط مفتاح:
```bash
DANDANA_KEY=كلمة-سر-طويلة ./start.sh          # ماك/لينكس
set DANDANA_KEY=كلمة-سر-طويلة && start.bat     # ويندوز
```
واكتب نفس الكلمة في الإعدادات ← «مفتاح الخادم».

### إذا يوتيوب رفض التحميل
- حدّث yt-dlp: أعد تشغيل `start.bat`/`start.sh` (يحدّث تلقائياً).
- تأكد أن `deno` مثبت (yt-dlp يحتاجه لفك حماية يوتيوب).
- آخر حل: صدّر ملف `cookies.txt` من متصفحك (إضافة «Get cookies.txt») وحطه بجانب `server.py`.

### Docker (اختياري)
```bash
docker build -t dandana dandana/server
docker run -p 8765:8765 -e DANDANA_KEY=... dandana
```

### متغيرات الخادم
| المتغير | الافتراضي | |
|---|---|---|
| `PORT` | `8765` | المنفذ |
| `DANDANA_KEY` | — | مفتاح مطلوب في كل طلب (`X-Dandana-Key` أو `?key=`) |
| `DANDANA_COOKIES` | `server/cookies.txt` إن وجد | ملف كوكيز يوتيوب |
| `DANDANA_PARALLEL` | `2` | عدد التحميلات المتزامنة |
| `DANDANA_KEEP_SECONDS` | `2700` | مدة بقاء الملف الجاهز على الخادم |

### واجهة الخادم
| | |
|---|---|
| `GET /api/health` | الحالة والإصدارات |
| `GET /api/search?q=&limit=&kind=video\|short` | بحث |
| `GET /api/related?id=` | ميكس يوتيوب لأغنية |
| `GET /api/playlist?url=` | محتويات قائمة تشغيل |
| `GET /api/meta?url=` | عنوان وصورة رابط (سريع) |
| `POST /api/jobs` `{url, kind, quality, format}` | بدء تحميل |
| `GET /api/jobs/{id}` · `GET /api/jobs/{id}/file` · `DELETE /api/jobs/{id}` | التقدم · الملف · إلغاء |
| `GET /api/stream?id=&kind=audio\|video` | تشغيل مباشر (ريلز/بدون تحميل) |
| `GET /api/radio?url=` | تمرير محطات http فقط |
| `GET /api/thumb?url=` | صور الغلاف |

الخادم يقدّم التطبيق نفسه أيضاً على `/`، للتجربة السريعة على الكمبيوتر.

## ملاحظات تقنية

- بدون أي build ولا مكتبات خارجية: JavaScript modules عادية. التخزين في IndexedDB (الملفات
  في مخزن منفصل عن البيانات). Service worker يخزّن واجهة التطبيق للعمل بدون إنترنت.
- iOS يسمح ببدء الصوت من الكود فقط بعد لمسة: التطبيق «يفتح» عنصر الصوت عند أول لمسة، وبعدها
  التنقل بين الأغاني وشاشة القفل يشتغلوا.
- الفيديو يتوقف في الخلفية على iOS؛ التطبيق يحوّله لصوت تلقائياً عند قفل الشاشة (قابل للإيقاف).
- مصادر خارجية بدون مفاتيح: Deezer (الاقتراحات والمقاطع التجريبية)، LRCLIB (الكلمات)،
  Radio Browser (الراديو)، خوادم cobalt (التحميل)، noembed (عنوان الرابط الملصوق).
- لماذا لا يحمّل التطبيق من يوتيوب مباشرة مثل التطبيقات الأصلية؟ تطبيقات App Store (مثل تطبيقات الطرب)
  تتصل بيوتيوب من داخل الآيفون نفسه. سفاري يمنع أي موقع ويب من ذلك (سياسة CORS)، فلازم وسيط: خوادم cobalt،
  أو خادم البيت.
