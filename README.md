# مِرصاد — أسعار الصرف والذهب في ليبيا

لوحة ويب تعرض سعر **الدولار واليورو في السوق الموازية** في مصراتة وطرابلس وبنغازي،
**السعر الرسمي لمصرف ليبيا المركزي**، و**أسعار الذهب** بجميع العيارات — مع مخططات
بيانية، وملاحظات تغيّر (منذ الصباح، أمس في نفس الوقت، خلال أسبوع)، وتحديث تلقائي.

الأرقام تُجمَع آلياً من مصادر ليبية منشورة. لا يوجد إدخال يدوي، ولا توجد أرقام مُختلَقة:
ما لم يصل يظهر كـ «—» أو بوسم يشرح حالته.

---

## ١) التشغيل — خطوتان

### أ. تفعيل النشر (GitHub Pages)

`Settings` ← `Pages` ← **Source: Deploy from a branch** ← الفرع `main` والمجلد **`/docs`** ← `Save`.

بعد دقيقة يصبح الرابط:

```
https://<اسم-المستخدم>.github.io/<اسم-المستودع>/
```

اخترنا النشر من فرع بدل النشر عبر Actions لأن كل عملية جمع تُنتج commit جديداً؛ النشر من
فرع يلتقط التحديث تلقائياً دون أن يستهلك دقائق Actions في كل مرة.

### ب. تفعيل الجمع التلقائي

`Settings` ← `Actions` ← `General` ← تحت **Workflow permissions** اختر
**Read and write permissions** ← `Save`.

> **مهم:** GitHub يشغّل المهام المجدولة على **الفرع الافتراضي فقط**. لن تبدأ دورة الجمع
> قبل دمج هذا العمل في `main`. لتجربتها فوراً: `Actions` ← `Collect rates` ← `Run workflow`.

## ٢) كيف تصل البيانات

```
كل ~١٠ دقائق (GitHub Actions)          كل ٥ دقائق (المتصفح)
   collector/collect.mjs                  docs/assets/js/app.js
            │                                      │
   مصادر السوق الموازية ─┐                        ├─ يقرأ docs/data/*.json
   مصرف ليبيا المركزي ──┼─► docs/data/latest.json │
   أسعار الذهب العالمية ─┘   docs/data/history.json└─ ويجلب سعر الذهب مباشرةً
                                                      من واجهة عالمية (CORS)
```

- **السوق الموازية:** تُقرأ من عدة مصادر منشورة، ويؤخذ **الوسيط** بينها بعد ترجيح
  المصدر الأقرب للسوق — حتى لا يُفسد مصدرٌ واحدٌ متأخر الرقم.
- **السعر الرسمي:** من صفحة أسعار الصرف في مصرف ليبيا المركزي، ويُستكمل من مرجع دولي
  إذا تعذّر الوصول.
- **الذهب:** `سعر الأونصة ÷ 31.1035 × نقاء العيار × سعر الدولار المعتمد`.
  يُحسب مرتين: بالسعر الرسمي، وبسعر السوق الموازية في كل مدينة.
- **الذهب لحظياً:** الصفحة تجلب سعر الأونصة من المتصفح كل ٥ دقائق وتعيد حساب كل
  العيارات، فلا تنتظر دورة الجمع التالية. إن فشل الجلب تبقى قيمة المجمّع دون أي عطل.

### الأوسمة

| الوسم | المعنى |
|---|---|
| `مشتق` | لم يُنشر رقم خاص بهذه المدينة، فعُرض سعر السوق العام |
| `قديم` | لم يصل رقم جديد في آخر جمع — هذه آخر قيمة معروفة |
| `أولي` | قيمة أولية موثّقة بتاريخها، تُستبدل عند أول تشغيل للمجمّع |
| `مباشر` | سعر ذهب مجلوب لحظياً من المتصفح، لا من آخر دورة جمع |

## ٣) البنية

```
collector/
  collect.mjs      المنسّق: يشغّل المصادر، يدمج، يكتب latest.json و history.json
  sources.mjs      محوّل لكل مصدر + استخراج الأسعار من النص العربي
  seed.mjs         بذرة أولية من أرقام منشورة بتواريخها
  lib/util.mjs     جلب مع مهلة وإعادة محاولة، تطبيع الأرقام والحروف العربية
docs/              الموقع (جذر GitHub Pages)
  index.html
  assets/css/app.css
  assets/js/{chart,data,ui,app}.js
  data/{latest,history}.json
```

المجمّع **بلا أي اعتمادية خارجية** — يعمل على Node 22 دون `npm install`.

## ٤) التطوير محلياً

```bash
# تشغيل دورة جمع حقيقية (تحتاج إنترنت)
node collector/collect.mjs

# دورة تجريبية بلا شبكة — تتحقق من الدمج والكتابة فقط
COLLECT_OFFLINE=1 node collector/collect.mjs

# إعادة كتابة البذرة الأولية
node collector/seed.mjs --force

# معاينة الموقع
cd docs && python3 -m http.server 8899   # ← http://localhost:8899
```

## ٥) صيانة المصادر

مواقع الأسعار الليبية تغيّر تنسيقها من حين لآخر. المجمّع مبني لذلك:

- كل مصدر **معزول**: إذا سقط أحدها تكتمل الدورة وتظهر حالته في جدول «المصادر وحالتها»
  أسفل الصفحة، مع سبب الفشل.
- الاستخراج **لا يعتمد على محدّدات CSS** بل على قرب الرقم من اسم المدينة/العملة داخل
  النص، مع نطاق معقول لكل عملة (`BANDS` في `collector/sources.mjs`) يرفض أي رقم شاذ.
- لإضافة مصدر: أضف سطراً إلى `PARALLEL_SOURCES` في `collector/sources.mjs`.
  الدالة تُرجع `{ rates, detail }` أو ترمي استثناءً — لا شيء آخر مطلوب.
- لتغيير ترجيح مصدر: عدّل `weight` (عدد أصواته في حساب الوسيط).

> **ملاحظة صريحة:** بيئة التطوير التي بُني فيها المشروع محجوبة عن الإنترنت، فلم يكن
> ممكناً اختبار المحوّلات على المواقع الحية. المنطق وتحليل النص مُختبَران على عيّنات،
> لكن **توقّع أن يحتاج مصدر أو اثنان لضبط بعد أول تشغيل** — وجدول حالة المصادر في
> الصفحة هو المكان الذي يخبرك أيها بالضبط.

## ٦) تنبيه

هذه أداة متابعة إرشادية تجمع أرقاماً منشورة علناً. أسعار السوق الموازية تتغيّر خلال
الدقيقة الواحدة وتختلف من صرّاف لآخر. راجع مصدرك قبل أي تحويل فعلي.
