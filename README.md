# سند — سكرتير شخصي ذكي على الواتساب

بوت واتساب يشتغل على رقم مخصص، يرد عليك وعلى عدد محدود من الأشخاص الموثوقين، يفهم **الرسائل الصوتية**، يدير **مواعيدك في تقويم جوجل**، يبعثلك **تذكيرات في الوقت اللي تحدده**، ويتعامل مع ملفاتك في **جوجل درايف** — كل هذا باللهجة الليبية.

## شنو يعمل؟

| القدرة | التفاصيل |
|---|---|
| 🧠 **عقل ذكي** | يجاوب على أي سؤال — معلومات، صياغة رسالة، ترجمة، حساب، رأي. مبني على Gemini |
| 🎙️ **الرسائل الصوتية** | تبعتله صوتية بالليبي ويفهمها ويرد عليها مباشرة |
| 📅 **المواعيد** | "سجلي موعد مع المحامي الخميس 4" → يتسجّل في تقويم جوجل فوراً |
| ⏰ **التذكيرات** | "ذكرني بكرة الساعة 8 بموعد الدكتور" → توصلك رسالة واتساب في وقتها بالضبط |
| 📁 **جوجل درايف** | "ابعتلي ملف العقد" → يدوّر عليه ويبعثه. وأي ملف تبعثله يتحفظ في درايف تلقائياً |
| 🖼️ **الصور والملفات** | يشوف الصور ويقرا ملفات PDF ويجاوب على أسئلتك عنها |
| 👥 **حتى 5 أشخاص** | كل واحد عنده محادثته وذاكرته وصلاحياته المنفصلة |
| 🔒 **أرقام محددة فقط** | أي رقم مش في القائمة يتجاهله تماماً |

## التثبيت في 6 خطوات

### 1) جهّز سيرفر

أي سيرفر لينكس (Ubuntu 22.04 أو أحدث) بذاكرة 1 جيجا فما فوق. راجع [`docs/SETUP-ORACLE.md`](docs/SETUP-ORACLE.md) للحصول على سيرفر **مجاني دائم** من Oracle.

### 2) نزّل المشروع

```bash
sudo apt update && sudo apt install -y git docker.io docker-compose-plugin ffmpeg
git clone <رابط-المستودع> boxsand && cd boxsand
```

### 3) احصل على مفتاح Gemini المجاني

افتح <https://aistudio.google.com/apikey> ← `Create API key` ← انسخ المفتاح.

```bash
cp .env.example .env
nano .env      # ضع GEMINI_API_KEY
```

### 4) اربط جوجل (التقويم والدرايف)

اتبع [`docs/SETUP-GOOGLE.md`](docs/SETUP-GOOGLE.md) للحصول على `GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET`، وبعدين:

```bash
npm install
npm run auth:google     # يعطيك رابط، توافق، وترجع تلصق الرابط
```

ضع `GOOGLE_REFRESH_TOKEN` الناتج في ملف `.env`.

> يمكنك تخطي هذه الخطوة مؤقتاً — البوت يشتغل بدونها لكن بدون تقويم ولا درايف.

### 5) حدّد الأرقام المسموح لها

```bash
cp config/config.example.json config/config.json
nano config/config.json
```

ضع رقمك أنت في `المالك`، وأرقام الـ5 أشخاص في `المستخدمون`.
**صيغة الرقم:** دولية بدون `+` وبدون صفر بادئ — مثال: `218911234567`.

تأكد إن كل شيء مضبوط:

```bash
npm run check
```

### 6) شغّل وامسح كود QR

```bash
docker compose up --build
```

بيطلعلك كود QR في الشاشة. من جوال **رقم البوت**:
واتساب ← الإعدادات ← **الأجهزة المرتبطة** ← **ربط جهاز** ← امسح الكود.

لما تشوف `✅ الاتصال بالواتساب تم بنجاح` — البوت شغّال. أوقفه بـ `Ctrl+C` وشغّله في الخلفية:

```bash
docker compose up -d
docker compose logs -f      # لمتابعة السجل
```

## الاستعمال

كلّمه في الواتساب عادي، بالنص أو بالصوت:

```
"شن عندي بكرة؟"
"سجلي موعد مع سالم الأحد 11 الصبح في المكتب"
"ذكرني كل يوم الساعة 7 بالدوا"
"ابعتلي ملف الفاتورة"
"لخصلي الملف هذا"          ← مع إرفاق PDF
"شن رايك في الموضوع هذا؟"
```

### أوامر خاصة

| الأمر | الوظيفة |
|---|---|
| `/حالة` | يعرض حالة البوت والصلاحيات والربط |
| `/مسح` | يمسح ذاكرة المحادثة ويبدأ من جديد |

## الضبط والتخصيص

كل السلوك يتحكم فيه ملف `config/config.json` بدون لمس الكود:

| الإعداد | الوظيفة |
|---|---|
| `اسم_السكرتير` | الاسم اللي يعرّف بيه نفسه |
| `تأخير_الرد_ثواني` | تأخير عشوائي قبل الرد حتى يبان طبيعي |
| `مهلة_تجميع_الرسائل_ثواني` | ينتظر شوية ويجمع الرسائل المتتابعة ويرد عليها مرة وحدة |
| `الرد_على_المجموعات` | الافتراضي `false` — ما يردش في المجموعات |
| `عدد_رسائل_الذاكرة` | كم رسالة سابقة يتذكرها في كل محادثة |
| `حد_الرسائل_في_الساعة` | سقف حماية من الحلقات اللانهائية |
| `حفظ_الملفات_الواردة_تلقائياً` | يحفظ أي ملف يوصله في درايف |
| `ساعات_العمل` | لو فعّلتها، يرد برسالة مختلفة خارج الدوام |
| `تعليمات_إضافية` | أي تعليمات خاصة تنضاف لشخصيته مباشرة |

### الصلاحيات

كل مستخدم له صفة (`المالك` أو `عضو`)، وكل صفة لها صلاحيات في قسم `الصلاحيات`:

```
قراءة_التقويم · تعديل_التقويم · التذكيرات · قراءة_درايف · رفع_درايف
```

الافتراضي: **المالك** له كل شيء، و**العضو** يشوف التقويم ويسجّل تذكيراته فقط — بدون تعديل مواعيد ولا وصول للدرايف.

### تعديل الشخصية واللهجة

افتح [`src/prompt.js`](src/prompt.js) وعدّل الأمثلة في قسم **اللهجة والأسلوب**. الأمثلة الحقيقية هي أقوى أداة لضبط النبرة — كل ما كانت قريبة من طريقة كلامك، كل ما كان الرد طبيعي أكثر.

## الصيانة

```bash
docker compose logs -f            # متابعة السجل
docker compose restart            # إعادة تشغيل
docker compose down               # إيقاف
docker compose up -d --build      # تحديث بعد تعديل الكود
```

**نسخة احتياطية:** كل شيء مهم في مجلد `data/` (جلسة الواتساب + المحادثات + التذكيرات).

```bash
tar czf backup-$(date +%F).tar.gz data config/config.json .env
```

## ملاحظات مهمة

- **الاتصال بالواتساب غير رسمي** (عبر مكتبة Baileys). بما إن البوت يرد على أرقام معروفة فقط وما يراسلش غرباء، خطر الحظر منخفض جداً — لكنه مش صفر. استعمل رقماً مخصصاً مش رقمك الأساسي.
- **جلسة الواتساب** محفوظة في `data/auth`. لو حذفتها بتحتاج تمسح QR من جديد.
- **الطبقة المجانية من Gemini** لها حدود على عدد الطلبات. كافية للاستعمال الشخصي، وتقدر ترفعها بتفعيل الفوترة لو احتجت.
- **لا تشارك `.env`** — فيه مفاتيحك الخاصة، وهو مستثنى من git أصلاً.
