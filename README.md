# سند — سكرتير شخصي ذكي

بوت ذكي يشتغل كسكرتير شخصي: ترد عليه بالنص أو بالصوت، يدير مواعيدك في تقويم جوجل، يبعثلك تذكيرات في وقتها بالضبط، ويتعامل مع ملفاتك في جوجل درايف — كل هذا باللهجة الليبية.

**تكلفة التشغيل: صفر.** بلا بطاقة بنكية، وبلا أي جهاز عندك.

---

## شنو يعمل؟

| القدرة | التفاصيل |
|---|---|
| 🧠 **عقل ذكي** | يجاوب على أي سؤال — معلومات، صياغة رسالة، ترجمة، حساب، رأي. مبني على Gemini |
| 🎙️ **الرسائل الصوتية** | تبعتله صوتية بالليبي ويفهمها ويرد عليها مباشرة |
| 📅 **المواعيد** | "سجلي موعد مع المحامي الخميس 4" → يتسجّل في تقويم جوجل فوراً |
| ⏰ **التذكيرات** | "ذكرني كل يوم الساعة 7 بالدوا" → توصلك رسالة في وقتها بالضبط |
| 📁 **جوجل درايف** | "ابعتلي ملف العقد" → يدوّر عليه ويبعثه. وأي ملف تبعثله يتحفظ تلقائياً |
| 🖼️ **الصور والملفات** | يشوف الصور ويقرا ملفات PDF ويجاوب على أسئلتك عنها |
| 👥 **حتى 5 أشخاص** | كل واحد عنده محادثته وذاكرته وصلاحياته المنفصلة |
| 🔒 **مغلق** | ما يردش إلا على من سجّلته أنت بكود دعوة |

## ليش تليجرام مش واتساب؟

الواتساب يحتاج برنامجاً يعمل 24 ساعة بلا انقطاع، وهذا يحتاج خادماً — وكل الخوادم (حتى المجانية منها) تطلب بطاقة بنكية للتحقق.

تليجرام يشتغل بطريقة مختلفة: خوادمه هي من تحتفظ بالاتصال، فالبوت يعيش على Cloudflare مجاناً بلا بطاقة وبلا جهاز. وفوق هذا: صفر خطر حظر، تذكيرات استباقية بلا قيود، وتعامل أفضل مع الملفات.

> 📂 نسخة الواتساب موجودة جاهزة في مجلد **[`whatsapp/`](whatsapp/)** — تشتغل على أي خادم لينكس لما تتوفر لك وسيلة دفع. نفس المزايا بالضبط.

## كيف يشتغل؟

```
رسالتك في تليجرام
      ↓
  Cloudflare Worker  ← يتحقق: هل أنت مصرّح لك؟
      ↓
  Gemini + الأدوات   ← تقويم • تذكيرات • درايف • ملاحظات
      ↓
   الرد بالليبي
```

وبالتوازي: **مؤقّت كل دقيقة** يفحص التذكيرات المستحقة ويبعثها.

## البنية

الكود كله في ملف واحد — `worker.js` — حتى تقدر تلصقه في لوحة Cloudflare بدون أدوات بناء:

| القسم | المحتوى |
|---|---|
| 1–3 | الإعدادات، الوقت، قاعدة البيانات |
| 4–5 | تليجرام، وجوجل (تقويم ودرايف) |
| 6 | الأدوات المتاحة للنموذج |
| 7–8 | شخصية السكرتير، وعقل Gemini |
| 9–10 | الأوامر، ومعالجة الرسائل |
| 11–13 | التذكيرات، صفحة الإعداد، المسارات |

## للمطوّرين

```bash
npm install
npx wrangler dev --local --test-scheduled    # تشغيل محلي
npx wrangler deploy                          # نشر عبر السطر
```

الإعدادات المحلية في `.dev.vars`، والربط في `wrangler.toml`.
النشر من لوحة Cloudflare لا يحتاج أياً من هذا.
