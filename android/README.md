# مخزون المكتبة — تطبيق أندرويد

الواجهة هي **الموقع نفسه** (مجلد `site`) محفوظاً داخل التطبيق: يُنسخ
تلقائياً عند كل بناء، فلا نسختان تفترقان. التطبيق يضيف:

- **مسح الباركود بالكاميرا** — زر بجانب خانة البحث. صنف واحد يطابق
  الرمز ⇦ تُفتح صفحته مباشرة.
- **زر الرجوع** — يغلق صفحة الصنف، ثم يرجع للرئيسية، ثم يمسح البحث،
  ولا يُغلق التطبيق إلا من الرئيسية.
- **الاتصال بالفرع** يفتح تطبيق الهاتف.

للعرض فقط، كالموقع: لا بيع ولا تعديل. يجلب البيانات من نفس خادم الربط
(العنوان وكلمة السر نفسهما).

## البناء

يحتاج JDK 17+ و Android SDK (platform 34، build-tools 34):

```
cd android
echo "sdk.dir=/مسار/android-sdk" > local.properties
gradle assembleRelease
```

الملف الناتج: `app/build/outputs/apk/release/app-release.apk`

## التوقيع

كل تحديث يجب أن يُوقَّع **بالمفتاح نفسه**، وإلا رفض التلفون تثبيته فوق
القديم. المفتاح عند صاحب المحل وحده، ولا يُرفع إلى GitHub. ضعه بجانب
هذا الملف مع `keystore.properties`:

```
storeFile=maktaba-stock.jks
storePassword=...
keyAlias=maktaba
keyPassword=...
```

بدونهما يُبنى التطبيق بلا توقيع نهائي.

عند كل تحديث ارفع `versionCode` في `app/build.gradle`.
