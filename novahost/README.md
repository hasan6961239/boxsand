# NOVA HOST

**منصة استضافة شخصية ذاتية الاستضافة — تعمل من هاتفك.**

ارفع ملف ZIP لموقعك، واحصل على رابط. نسخ متعددة، تراجع فوري، محرر ملفات،
مراقبة حقيقية للجهاز — كل ذلك من Samsung Galaxy A36 يعمل ٢٤/٧ في بيتك.

مستوحاة من تجربة Netlify، لكنها تعمل على أجهزتك أنت.

```
┌──────────────────────────────────────────────────────────────┐
│  New Project → Upload ZIP → Deploy → Open Website             │
│                                                               │
│  أربع خطوات. بلا طرفية، بلا إعدادات، بلا اشتراك شهري.        │
└──────────────────────────────────────────────────────────────┘
```

---

## ما الذي يميّز هذا المشروع

| | |
|---|---|
| **صفر تبعيات** | لا `npm install` على الهاتف. انسخ وشغّل. |
| **صفر تكلفة شهرية** | الخادم هاتفك، والقاعدة ملف، والشهادة مجانية |
| **نشر ذرّي** | موقعك الحالي لا يُمسّ حتى تنجح النسخة الجديدة بالكامل |
| **تراجع فوري** | تبديل مؤشر، بلا إعادة رفع، في أجزاء من الثانية |
| **أمان حقيقي** | قارئ ZIP مكتوب خصيصاً يوقف Path Traversal وZIP Bombs |
| **عربي وإنجليزي** | واجهة كاملة بالاتجاهين RTL/LTR |
| **أرقام صادقة** | ما لا يمكن قراءته من أندرويد يظهر «غير متاح» — لا أرقام مخترعة |

## البدء السريع

### على اللابتوب (Windows)

```powershell
cd novahost
.\scripts\dev.ps1 setup
.\scripts\dev.ps1 start
```

افتح `http://localhost:8080` ← معالج الإعداد ← أنشئ حساباً.

### على الهاتف (Termux)

```bash
pkg update && pkg install -y git
git clone <رابط-المستودع> ~/novahost
cd ~/novahost/novahost
bash scripts/install-termux.sh
scripts/start.sh
```

ثم اتبع **الخطوات الثلاث اليدوية** في أندرويد — بدونها سيتوقف السيرفر بعد
دقائق. التفاصيل في [ANDROID-SERVER.md](docs/ANDROID-SERVER.md).

## بنية المشروع

```
novahost/
├── backend/src/
│   ├── server.js        نقطة الدخول
│   ├── config.js        الإعدادات من .env
│   ├── db/              SQLite + الهجرات + مستودعات (كل SQL هنا)
│   ├── http/            الموجّه، الطلب، الأمان، الملفات الثابتة
│   ├── routes/          مسارات الـAPI
│   ├── services/        المنطق: deploy · zip · sites · stats · backup
│   └── util/            أدوات نقية قابلة للاختبار
├── backend/test/        118 اختباراً بـnode:test
├── frontend/            لوحة التحكم — بلا خطوة بناء
├── scripts/             تشغيل وصيانة (bash لـTermux · ps1 لويندوز)
├── docs/                كل الوثائق
└── data/                يُنشأ وقت التشغيل — مُستثنى من Git
```

## كيف يعمل النشر

```
رفع ZIP
   ↓ بثّ إلى القرص مع سقف حجم (لا تحميل في الذاكرة)
التحقق
   ↓ التوقيع · عدد الملفات · حجم الفك · نسبة الانضغاط · المسارات
الفك
   ↓ إلى مجلد مؤقت <id>.partial
فحص الصحة
   ↓ هل يوجد index.html؟
النشر الذرّي
   ↓ إعادة تسمية واحدة — هذه اللحظة هي التبديل
تحديث المؤشر
   ↓ داخل معاملة + ملف current.txt
READY
```

أي فشل في أي خطوة: النشر يصبح FAILED بسبب واضح في السجل، والمجلد المؤقت
يُحذف، **والموقع المنشور لم يُمسّ إطلاقاً**.

## ماذا يعمل الآن

- ✅ معالج إعداد أول، تسجيل دخول، جلسات، CSRF، تحديد معدل، قفل تصاعدي
- ✅ مشاريع: إنشاء/تعديل/حذف/إيقاف، توليد slug من الاسم العربي
- ✅ رفع ZIP مع شريط تقدّم حقيقي وخط أنابيب نشر ذرّي
- ✅ نسخ متعددة مع تراجع فوري وسياسة احتفاظ
- ✅ تقديم المواقع: نطاقات فرعية · `*.localhost` · sslip.io · مسارات
- ✅ مدير ملفات + محرر أكواد بتلوين نحوي (بلا CDN)
- ✅ نطاقات مخصصة مع تحقق DNS
- ✅ مراقبة حقيقية: معالج، ذاكرة، تخزين، بطارية، حرارة، شبكة
- ✅ سجلات تطبيق وأمان ونشاط + نسخ احتياطي واستعادة
- ✅ عربي/إنجليزي، RTL، داكن/فاتح، يعمل على الآيفون
- ✅ رمز QR لكل مشروع (مُولَّد محلياً، بلا خدمة خارجية)
- ✅ 118 اختباراً

## ما هو مؤجَّل عن قصد

| | لماذا |
|---|---|
| **تشغيل كود مرفوع** (Node/PHP/Python) | يحتاج عزلاً حقيقياً (sandbox). بدونه أي موقع ترفعه يملك الجهاز. استضافة ثابتة فقط تزيل فئة RCE كاملة. |
| **بناء أطر العمل** (React/Next/Vite) | نفس السبب. ابنِ على اللابتوب وارفع مجلد `dist/`. |
| **CLI** | الجداول والدوال جاهزة في `db/repo/apikeys.js` — الإضافة لاحقاً بلا هجرة. |
| **تكامل Git** | المعمارية تسمح به: مصدر نشر إضافي بجانب `zip` و`editor`. |
| **مصادقة ثنائية** | البديل المجاني والأقوى الآن: Cloudflare Access أمام اللوحة. |

## التكلفة الحقيقية

| | |
|---|---|
| الخادم، Termux، Node، SQLite، التخزين، المنصة | **0** |
| حساب Cloudflare + النفق + الشهادة + wildcard DNS | **0** |
| رابط مؤقت (trycloudflare) | **0** — لكنه يتغيّر مع كل تشغيل |
| **نطاق ثابت بنطاقات فرعية** | **~10–15 دولاراً سنوياً** ← الشيء الوحيد غير المجاني |

القيود المجانية التي يجب أن تعرفها: كلاودفلير ترفض الرفع فوق **100 ميجابايت**،
والشهادة المجانية تغطي **مستوى نطاق واحداً فقط**. كلاهما مأخوذ في الحسبان في
تصميم المشروع — التفاصيل في [ANALYSIS.md](docs/ANALYSIS.md).
