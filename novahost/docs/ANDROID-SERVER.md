# تحويل Samsung Galaxy A36 5G إلى سيرفر

> **إن كانت هذه أول مرة، ابدأ من [ANDROID-SERVER-SETUP.md](ANDROID-SERVER-SETUP.md).**
> ذلك الملف هو الدليل التنفيذي خطوة بخطوة — أوامر جاهزة للنسخ، وإعدادات One UI
> بأسمائها، وقوائم اختبار، وقسم حلول للمشاكل. هذا الملف مرجع أقصر يشرح *لماذا*
> يعمل الأمر بهذه الطريقة.

هذا الدليل كامل: من هاتف عادي إلى سيرفر يعمل ٢٤/٧. نفّذ الخطوات بالترتيب.

> **قبل أن تبدأ — الحقيقة كاملة:** أندرويد ليس نظام خادم. الخطوات الثلاث في
> القسم ٣ ليست «تحسينات اختيارية»، بل هي الفرق بين سيرفر يعمل أسابيع وسيرفر
> يتوقف بعد دقائق من إطفاء الشاشة. لا توجد طريقة برمجية لتجاوزها.

---

## ١) تثبيت Termux

**لا تثبّت Termux من Google Play.** نسخة المتجر متوقفة عن التحديث منذ سنوات
وستفشل معك عند تثبيت الحزم.

1. ثبّت **F-Droid** من [f-droid.org](https://f-droid.org) (أو نزّل APK من
   [github.com/termux/termux-app/releases](https://github.com/termux/termux-app/releases)).
2. من F-Droid ثبّت:
   - **Termux** — الطرفية نفسها
   - **Termux:Boot** — لتشغيل السيرفر بعد إعادة تشغيل الهاتف
   - **Termux:API** — لقراءة البطارية والحرارة

> **مهم جداً:** الثلاثة يجب أن تكون من **نفس المصدر**. أندرويد يرفض تثبيت
> تطبيقات إضافية موقّعة بمفتاح مختلف عن التطبيق الأساسي. إن ثبّت Termux من
> F-Droid و Termux:Boot من GitHub فسيفشل التثبيت برسالة غامضة.

افتح Termux مرة واحدة، ثم:

```bash
pkg update && pkg upgrade -y
```

## ٢) جلب المشروع وتشغيل الإعداد

```bash
pkg install -y git
git clone <رابط-المستودع> ~/novahost
cd ~/novahost/novahost
bash scripts/install-termux.sh
```

السكربت يثبّت الحزم، يُنشئ `.env` ويولّد `SESSION_SECRET`، يهيّئ قاعدة البيانات،
ويكتب سكربت الإقلاع. هو **آمن للتكرار** — شغّله مرة أخرى بلا قلق إن فشل شيء.

## ٣) إعدادات أندرويد — الخطوة التي لا يستطيع أي سكربت تنفيذها

### أ. افتح تطبيق Termux:Boot مرة واحدة

اضغط على أيقونته. سيفتح شاشة فارغة تقريباً — هذا طبيعي. **قبل هذه الضغطة لن
يعمل سكربت الإقلاع أبداً**، مهما كان صحيحاً.

### ب. ألغِ تقييد البطارية

`الإعدادات` ← `التطبيقات` ← `Termux` ← `البطارية` ← اختر **غير مقيّد**.

كرّر نفس الشيء لـ **Termux:Boot** و **Termux:API**.

ثم في One UI: `الإعدادات` ← `العناية بالجهاز` ← `البطارية` ← `حدود الاستخدام في
الخلفية` ← تأكد أن Termux **ليس** في قائمة «التطبيقات النائمة» أو «النائمة
بعمق»، وأطفئ **«إيقاف التطبيقات غير المستخدمة»**.

> سامسونج أكثر عدوانية من أندرويد الخام في إنهاء التطبيقات. تخطّي هذه الخطوة
> هو السبب الأول لتوقف السيرفر.

### ج. أبقِ الواي فاي نشطاً أثناء السكون

`الإعدادات` ← `الاتصالات` ← `Wi-Fi` ← (⋮) ← `متقدم` ← فعّل **«إبقاء Wi-Fi
مشغّلاً أثناء السكون»**.

واحجز عنوان IP ثابتاً للهاتف من صفحة إعدادات الراوتر (DHCP Reservation) حتى لا
يتغيّر العنوان المحلي عند كل إعادة تشغيل.

## ٤) التشغيل

```bash
scripts/start.sh
```

سيطبع لك العناوين. افتح من اللابتوب:

```
http://192.168.1.XX:8080
```

ستظهر شاشة **الإعداد الأول** — أنشئ حساب المدير. هذه الشاشة تُغلق نفسها بعد
إنشاء الحساب الأول ولا يمكن استخدامها مرة أخرى.

## ٥) أوامر التشغيل اليومية

| الأمر | ماذا يفعل |
|---|---|
| `scripts/start.sh` | تشغيل في الخلفية تحت الإشراف |
| `scripts/start.sh -f` | تشغيل في الطرفية لرؤية السجل مباشرة |
| `scripts/stop.sh` | إيقاف السيرفر والمشرف معاً |
| `scripts/restart.sh` | إعادة تشغيل |
| `scripts/status.sh` | الحالة + الصحة + العناوين |
| `scripts/logs.sh` | متابعة سجل التطبيق |
| `scripts/logs.sh server` | متابعة سجل المشرف (أخطاء الإقلاع) |
| `scripts/backup.sh` | نسخة احتياطية |
| `scripts/backup.sh --to-downloads` | نسخة + نقلها إلى مجلد التنزيلات |
| `npm run doctor` | فحص شامل يخبرك بما هو معطوب |

## ٦) الإدارة من اللابتوب عبر SSH

على الهاتف، مرة واحدة:

```bash
pkg install -y openssh
passwd                 # اختر كلمة مرور لحساب Termux
whoami                 # اكتب الناتج (مثل u0_a123) — هذا اسم المستخدم
sshd                   # تشغيل خادم SSH
```

من ويندوز (PowerShell):

```powershell
ssh -p 8022 u0_a123@192.168.1.XX
```

> منفذ SSH في Termux هو **8022** وليس 22، لأن المنافذ تحت 1024 تحتاج صلاحيات
> لا يملكها تطبيق عادي على أندرويد.

**استخدام المفاتيح بدل كلمة المرور** (أفضل بكثير):

```powershell
# على ويندوز
ssh-keygen -t ed25519
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh -p 8022 u0_a123@192.168.1.XX "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

**نسخ المشروع من اللابتوب إلى الهاتف:**

```powershell
.\scripts\dev.ps1 push -PhoneHost 192.168.1.XX -PhoneUser u0_a123
```

**لتشغيل sshd تلقائياً مع Termux:**

```bash
pkg install -y termux-services
sv-enable sshd
```

## ٧) ماذا يحدث بعد إعادة تشغيل الهاتف؟

```
الهاتف يقلع
   ↓
Termux:Boot يشتغل (لأنك فتحت تطبيقه مرة واحدة)
   ↓
ينفّذ ~/.termux/boot/novahost
   ↓
termux-wake-lock ← يمنع التجميد
   ↓
انتظار ١٥ ثانية ← ليجد الواي فاي
   ↓
scripts/start.sh ← يشغّل المشرف
   ↓
المشرف يشغّل السيرفر ويعيد تشغيله إن سقط
```

البيانات كلها في `data/` على تخزين Termux الداخلي، فهي تنجو من إعادة التشغيل
تلقائياً: قاعدة البيانات، المشاريع، النشرات، الإعدادات.

**للتأكد أن الإقلاع التلقائي يعمل:** أعد تشغيل الهاتف فعلاً، انتظر دقيقة، ثم من
اللابتوب افتح `http://192.168.1.XX:8080`. إن لم يعمل، افتح Termux وشغّل
`scripts/logs.sh server`.

## ٨) حل المشاكل

### السيرفر يتوقف بعد دقائق من إطفاء الشاشة
السبب في ٩٩٪ من الحالات: البطارية. راجع القسم ٣-ب. تأكد أيضاً من ظهور إشعار
دائم من Termux يقول "wake lock held" — إن لم يظهر فـ`termux-wake-lock` لم يُنفَّذ.

### `scripts/start.sh` يقول "Port 8080 is already in use"
نسخة تعمل بالفعل:
```bash
scripts/status.sh      # تأكد
scripts/stop.sh        # أوقفها
```

### لا أستطيع الوصول من اللابتوب
1. تأكد أن الجهازين على **نفس شبكة الواي فاي** (لا شبكة ضيوف).
2. تأكد أن `HOST=0.0.0.0` في `.env` — لو كانت `127.0.0.1` فالسيرفر يستمع محلياً فقط.
3. بعض الراوترات تفعّل **AP Isolation** التي تمنع الأجهزة من رؤية بعضها. أطفئها.
4. من الهاتف نفسه: `curl http://localhost:8080/health` — إن نجح فالمشكلة في الشبكة لا في السيرفر.

### `pkg install` يفشل
```bash
termux-change-repo     # اختر مرآة أقرب
pkg update
```

### البطارية والحرارة تظهران «غير متاح»
ثبّت **Termux:API** من نفس مصدر Termux، ثم:
```bash
pkg install -y termux-api
termux-battery-status  # يجب أن يطبع JSON
```
إن طلب إذناً، اقبله. وإن بقي غير متاح فجهازك لا يصرّح بهذه القراءة — وهذا
طبيعي على بعض الأجهزة، والمنصة لن تخترع رقماً.

### إحصاءات الشبكة «غير متاح»
هذا **متوقع** على أندرويد ١٠ فما فوق: النظام يحجب `/proc/net/dev` عن التطبيقات.
لا يوجد حل بدون صلاحيات root.

### قاعدة البيانات تبدو تالفة
```bash
scripts/stop.sh
node backend/src/cli.js list-backups
node backend/src/cli.js restore data/storage/backups/backup-....zip
scripts/start.sh
```

### الهاتف يسخن
- استخدم **شاحناً بطيئاً** (5W) بدل السريع. الشحن السريع الدائم هو أسوأ ما
  يمكن فعله ببطارية ستبقى موصولة ٢٤ ساعة.
- أبقِ الشاشة مطفأة، والهاتف في مكان مفتوح وليس داخل درج أو حافظة.
- إن تجاوزت الحرارة ٤٥ درجة باستمرار، ستظهر لك اللوحة تحذيراً.

## ٩) نصائح لطول العمر

- **البطارية:** إبقاء الهاتف على ١٠٠٪ دائماً يستهلك عمرها. إن كان جهازك يدعم
  «حماية البطارية» (تحديد الشحن عند ٨٥٪) في `العناية بالجهاز` ← `البطارية`،
  فعّلها. هذا يطيل عمر البطارية بشكل ملموس.
- **التخزين:** راقب صفحة السيرفر. الذاكرة الوامضة تتآكل بالكتابة، ولهذا صُمّم
  المشروع ليكتب أقل قدر ممكن (قاعدة البيانات في وضع WAL، والسجلات محدودة المدة).
- **النسخ الاحتياطي:** `scripts/backup.sh --to-downloads` أسبوعياً، وانسخ الملف
  إلى اللابتوب. الهاتف قد يُسرق أو يقع.
- **التحديثات:** `pkg upgrade` شهرياً. بعدها `scripts/restart.sh` و`npm test`.
