# مصروفي 💰

تطبيق شخصي لمصاريفك وديونك ومرتباتك — يتركّب على الآيفون من Safari ويخدم زي التطبيقات العادية.

- **المصاريف والدخل** ببنود وأيقونات، سجل كامل بالبحث والفلاتر.
- **مرتب المكتب** (2000 د.ل يوم 20) مع **سحوبات الدرج**: تنضاف لرصيدك توة، وتنخصم من المرتب يوم نزوله، والتطبيق يحسب الصافي وحده.
- **مرتب الدولة** (650 د.ل) تسجّله بضغطة لما ينزل.
- **الديون** اللي ليك واللي عليك: دفعات، مواعيد، تذكير بواتساب، وكشف حساب لكل شخص.
- **الميزانية** الشهرية ولكل بند، **أهداف ادخار**، **مصاريف ثابتة** تتسجل وحدها، و**تقارير** برسوم.
- **إشعارات**: تذكير يومي، يوم المرتب، مواعيد الديون، والميزانية — توصلك حتى والتطبيق مقفول.
- **مزامنة** بين أجهزتك بحساب (إيميل وكلمة سر)، ويخدم بدون نت.
- ثيمات (فاتح/داكن/تلقائي) و8 ألوان، أنيميشن، وخط IBM Plex Sans Arabic.

## التشغيل لأول مرة (مرة وحدة)

1. **النشر:** المشروع على Netlify اسمه `masroufi-1ntk` ← الرابط `https://masroufi-1ntk.netlify.app`.
   مفاتيح الإشعارات (`VAPID_PUBLIC_KEY` و`VAPID_PRIVATE_KEY`) محطوطة في إعدادات المشروع.
2. **فعّل الحسابات:** افتح `https://app.netlify.com/projects/masroufi-1ntk/identity` واضغط **Enable Identity**.
   أول حساب يتعمل في الموقع يصير هو صاحب التطبيق، وأي تسجيل بعده يترفض
   (أو حط الإيميلات المسموحة في متغير `ALLOWED_EMAILS` مفصولة بفاصلة).
3. **ركّبه على الآيفون:** افتح الرابط من **Safari** ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية** ← افتحه من الأيقونة.
4. من داخل التطبيق: الإعدادات ← الحساب ← **أعمل حساب**، وبعدها الإعدادات ← الإشعارات ← **فعّل الإشعارات**.

## للمطوّر

```bash
npm install
npm run dev     # يبني ويراقب، ويفتح على http://localhost:8787 (افتح ?seed=demo لبيانات تجريبية)
npm test        # اختبارات المنطق والمزامنة والتذكيرات
npm run build   # النسخة النهائية في dist/
```
