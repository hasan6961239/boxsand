# المثبِّت

يبني `Qirtasiya-Setup-<الإصدار>.exe` — مثبِّت ويندوز عادي بواجهة عربية.

## البناء

```bash
makensis -DVERSION=2.5 installer/qirtasiya.nsi
```

يحتاج `makensis` (حزمة `nsis`). **يعمل من لينكس كما يعمل من ويندوز** —
NSIS يبني مثبِّتات ويندوز من أي نظام. ابنِ `build/Qirtasiya-1.exe` أولاً.

على ويندوز: نزّل NSIS من nsis.sourceforge.io ثم نفّذ الأمر نفسه.

## ماذا يفعل

| | |
|---|---|
| مكان التثبيت | `C:\Program Files\Qirtasiya` |
| الصلاحية | مدير (مرة واحدة عند التثبيت) |
| الاختصارات | سطح المكتب + قائمة ابدأ |
| الإلغاء | يظهر في «التطبيقات المثبَّتة» مثل أي برنامج |
| **البيانات** | `%LocalAppData%\Qirtasiya\data` |

## الترقية

يقرأ المثبِّت رقم النسخة من السجلّ. إن وجد نسخة سابقة عرض صفحة تقول:
«وُجدت النسخة X — سيُحدَّث إلى Y، وبياناتك تبقى كما هي»، ثم يغلق
البرنامج إن كان يعمل ويستبدل الملف.

**البيانات لا تُمسّ**: هي خارج مجلد البرنامج أصلاً، فالتحديث لا يصل إليها.

## الإلغاء

يسأل: «أبقِ بياناتي على الجهاز» — والعلامة موضوعة افتراضياً. لا تُحذف
البيانات إلا بإزالتها صراحةً. والإلغاء الصامت (`/S`) يُبقيها دائماً.

## وضعان للبرنامج

الملف التنفيذي نفسه يعمل بطريقتين، ويميّز بينهما بملف `installed.flag`
الذي يضعه المثبِّت بجانبه:

- **مثبَّت** (العلامة موجودة): البيانات في `%LocalAppData%\Qirtasiya\data`.
  مسار ثابت لا يتغيّر مع إعادة التثبيت.
- **محمول** (بلا علامة): البيانات في مجلد `data` بجانب الملف. ينفع
  لتشغيله من ذاكرة USB بلا تثبيت.

سابقاً كان المسار الاحتياطي يحمل بصمة مجلد البرنامج (`inst_<hash>`)،
فنقل الملف كان يعني مجلد بيانات آخر — أي بيانات تبدو ضائعة. البرنامج
الآن ينقل تلقائياً من أي مجلد `inst_*` قديم عند أول تشغيل.
