# الحصول على سيرفر مجاني دائم من Oracle Cloud

Oracle تقدّم **طبقة مجانية دائمة** (Always Free) — مش تجربة مؤقتة. تكفي البوت هذا وزيادة.

## قبل ما تبدأ

- **بطاقة بنكية للتحقق فقط.** Oracle تسحب مبلغاً رمزياً (حوالي دولار) ويترجّعلك خلال أيام. ما تتحاسبش على الطبقة المجانية إلا لو أنت بنفسك رقّيت الحساب يدوياً.
- **بريد إلكتروني ورقم هاتف.**
- الحساب اسمه Free Tier ويبقى مجانياً ما لم ترقّه أنت.

## الخطوات

### 1) التسجيل

<https://www.oracle.com/cloud/free/> ← `Start for free`

اختر المنطقة (Region) الأقرب لليبيا — **Frankfurt** أو **Amsterdam** أو **Milan**. ⚠️ المنطقة **ما تتغيّرش بعد التسجيل**، فاختر بعناية.

### 2) أنشئ السيرفر

من لوحة التحكم: `Compute` ← `Instances` ← `Create Instance`

| الإعداد | القيمة |
|---|---|
| **Image** | Canonical Ubuntu 22.04 (أو أحدث) |
| **Shape** | `VM.Standard.A1.Flex` — اختر **2 OCPU** و **6 GB** ذاكرة |
| **SSH keys** | اختر `Generate a key pair` و **نزّل المفتاح الخاص واحفظه** |

> **إذا ظهرت رسالة "Out of capacity"** فالسعة ممتلئة مؤقتاً في منطقتك — وهذا شائع. جرّب:
> - `VM.Standard.E2.1.Micro` بدل ARM (أضعف لكنه متاح أكثر، ويكفي البوت)
> - أعد المحاولة في أوقات مختلفة من اليوم — عادة تنجح خلال يوم أو يومين

### 3) افتح جدار الحماية

الطبقة المجانية تقفل المنافذ افتراضياً. البوت هذا **ما يحتاجش أي منفذ مفتوح** لأنه يتصل للخارج فقط — فتقدر تتجاوز هذه الخطوة.

### 4) ادخل للسيرفر

من جهازك أو من تطبيق **Termius** على الجوال:

```bash
chmod 600 مفتاحك.key
ssh -i مفتاحك.key ubuntu@<عنوان-IP-تاعك>
```

### 5) ثبّت المتطلبات

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git ffmpeg docker.io docker-compose-plugin
sudo usermod -aG docker $USER && newgrp docker
```

### 6) كمّل من README

ارجع لملف [`README.md`](../README.md) من الخطوة 2 وكمّل التثبيت عادي.

## بدائل لو Oracle ما نجحتش

| الخيار | التكلفة | ملاحظة |
|---|---|---|
| **Google Cloud** | جهاز `e2-micro` مجاني شهرياً في مناطق أمريكية محددة | أضعف لكنه يكفي |
| **Hetzner** | من ~4 يورو شهرياً | ممتاز وموثوق، مراكزه في ألمانيا وفنلندا |
| **RackNerd** | عروض سنوية تصل لحدود دولار شهرياً | رخيص جداً، ابحث عن عروضهم السنوية |
| **Contabo** | من ~5 دولار شهرياً | موارد كبيرة مقابل السعر |

الكود نفسه يشتغل على أي منها بلا أي تعديل.

## نصيحة أخيرة

فعّل إعادة التشغيل التلقائي حتى لو انطفى السيرفر:

```bash
sudo systemctl enable docker
```

`docker compose up -d` مع `restart: unless-stopped` (موجود أصلاً في الإعدادات) يضمن رجوع البوت تلقائياً بعد أي إعادة تشغيل.
