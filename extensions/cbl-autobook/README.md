# مساعد حجز CBL (إضافة كروم)

## التثبيت
1. فك ضغط `cbl-autobook.zip` في مجلد.
2. افتح `chrome://extensions` وفعّل **وضع المطوّر**.
3. اضغط **تحميل إضافة غير مُعبأة** (Load unpacked) واختر المجلد.

## طريقة العمل
بعد الدخول بحساب العميل في `fcms.cbl.gov.ly`:
1. تفتح الحسابات واحد واحد لين تلقى حساب **مصرف الأمان**. لو ما فيش، توقف وتكتب "لا يوجد حساب في مصرف الأمان".
2. لو الحساب عليه طلب سابق، توقف وتسألك (زر "متابعة على أي حال").
3. تضغط **إضافة طلب جديد** وتعبي: نوع الطلب = بطاقة، نوع الإيداع = تحويل بنكي، المدينة = مصراتة، القيمة = 2000.
4. توقف عند **مصدر الأموال**. الباقي (مصدر الأموال، معلومات أخرى، الموافقات، فحص Cloudflare، إرسال) يكمّله الموظف.

القيم تتغير من نافذة الإضافة. زر "إعادة التشغيل للعميل الحالي" يعيد الخطوات من الأول، وزر "إيقاف" في الشريط الأزرق يوقفها.
